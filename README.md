# Climate Change Analyzer

This is a Python-based tool designed to analyze climate change data. The application focuses on analyzing climate change trends using various machine learning algorithms, visualizations, and data processing techniques.

## Features

- **Data Processing:** Load, clean, and normalize climate datasets.
- **Machine Learning:** Implemented algorithms for climate parameter prediction, data clustering, and anomaly detection.
- **Visualizations:** Interactive visualizations for data insights, including scatter plots, regression lines, and more.
- **Command-line Interface (CLI):** A user-friendly CLI to interact with the tool and display results.
  
## Technologies Used

- Python 3.x
- Pandas for data manipulation
- NumPy for numerical operations
- Matplotlib and Plotly for data visualization
- Scikit-learn for machine learning algorithms
- Api from https://global-warming.org/

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/BlakHammar/climate_change_analyzer.git

2. Navigate into the project directory:

    cd climate_change_analyzer

3. Create a virtual environment:

    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`

4. Install the required dependencies: 

    pip install -r requirements.txt

5. Run the program:

    py src/main.py
